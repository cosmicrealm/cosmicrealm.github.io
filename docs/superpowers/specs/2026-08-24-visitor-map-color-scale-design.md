# Global Reach 彩色访问地图设计

## 目标

让主页 `Global Reach` 地图按国家访问量呈现明确的彩色层级，同时保留全站已经确定的纯白/纯黑主题。颜色只属于数据可视化，不扩散到导航、按钮或其他主页内容。

## 视觉规则

- 未产生访问的国家继续使用当前中性色地图底色。
- 已访问国家按相对访问量映射到连续色阶：低访问量为蓝色，中间为绿色，高访问量为橙色。
- 使用当前国家访问量除以最高国家访问量得到相对强度，并沿用平方根缩放，避免少数高访问国家压缩其他国家的色彩差异。
- 地图下方增加紧凑图例，标明 `Fewer visits` 与 `More visits`，使颜色含义可理解。
- 浅色模式使用较深色阶保证白底对比度；深色模式提高亮度与饱和度，保证黑底可读。
- 不改变统计接口、访问记录逻辑、IP 隐私边界或 Cloudflare Worker / D1 数据结构。

## 实现边界

- `assets/js/visitor-analytics.js` 只负责计算每个已访问国家的标准化色相值，并写入 CSS 自定义属性。
- `_sass/layout/_home.scss` 负责浅色/深色模式下的填充颜色、描边和图例渐变。
- `_includes/home-visitor-stats.html` 增加静态图例标记，不引入新的依赖。
- 未访问国家不得残留上一次渲染的行内色彩属性。

## 验收标准

1. 当摘要包含多个不同访问量的国家时，地图至少呈现两种不同的非黑白颜色。
2. 最高访问量国家显示为橙色端，较低访问量国家向蓝色端移动。
3. 浅色与深色模式下地图和图例均清晰可见，页面无横向溢出。
4. 现有访问统计、缓存、隐私和不可用状态行为保持不变。
5. 单元测试、主页浏览器 QA、访问统计结构检查和 Jekyll 构建检查通过。
