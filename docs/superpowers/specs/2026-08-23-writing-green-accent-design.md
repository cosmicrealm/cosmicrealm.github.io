# Writing 浅绿色强调色设计

## 目标

让 `/writing/` 的日期卡片、标签筛选、文章标签和链接下划线使用克制的浅绿色体系，同时保留站点已经确定的纯白浅色画布和纯黑深色画布。

## 视觉范围

- 配色仅作用于 `#main.blog-filter-layout`，不会影响导航栏、主页、Projects、Publications、Foundations 或文章详情页。
- 浅色模式使用 `#EAF4ED` 作为柔和底色、`#5F8F72` 作为强调色、`#315D46` 作为高对比文字和选中态底色。
- 深色模式使用 `rgba(168, 213, 184, 0.14)` 作为柔和底色、`#A8D5B8` 作为强调色、`#C8EAD3` 作为高对比强调色。
- Writing 页正文与页面背景继续继承全站黑白主题，不新增绿色大面积背景。

## 交互与可访问性

- 日期卡片、筛选标签、文章标签和标题下划线继承 Writing 页局部 token。
- 选中和悬停状态使用深色填充，并通过 `--global-on-base-color` 在浅色和深色主题中自动选择白字或黑字。
- 保留现有键盘交互、筛选逻辑、标签结构和响应式布局。

## 验收

- 浏览器分别验证浅色和深色 Writing 页的局部 token 与选中按钮实际颜色。
- 确认页面背景仍为纯白或纯黑，导航栏强调色仍为全站黑白色。
- 完整站点浏览器回归、架构检查和 `git diff --check` 通过。
